# Helse og ernæring (Vg1 Naturfag)

En moderne, interaktiv klasseromspresentasjon bygget med **React, TypeScript, Vite og Tailwind CSS** i samme stil og klasseromsflyt som [`hanselaa-code/big-bang`](https://github.com/hanselaa-code/big-bang).

## Kompetansemål (læreplanen i naturfag)

- **KM1:** *Gjøre rede for funksjonene til noen næringsstoffer og diskutere hvorfor et variert kosthold er viktig i et helse- og bærekraftsperspektiv*
- **KM2:** *Drøfte aktuelle helse- og livsstilsspørsmål og vurdere pålitelighet i informasjon fra ulike kilder*

## 7 Undertemaer i tankekartet

1. **Næringsstoffene** – Karbohydrater, proteiner, fett, vitaminer, mineraler og kostfiber
2. **Fordøyelsen** – Mekanisk og kjemisk nedbrytning, enzymer, galle og tarmtotter
3. **Omsetning & celleånding** – Glykolyse, sitronsyresyklus, elektrontransportkjeden og ATP
4. **Væskebalanse, aerob & anaerob** – Osmose, elektrolytter, termoregulering og melkesyre/laktat
5. **Trening** – Superkompensasjon, utholdenhet (VO₂-maks), styrke, skjelett og søvn
6. **Generell helse og kosthold** – Energibalanse, tallerkenmodellen, kostråd og klimaavtrykk (CO₂e)
7. **Kildekritikk & kostholdsråd** – TONE-prinsippet, evidenshierarkiet og interessekonflikter

## Hurtigguide i klasserommet

| Tast / Handling | Funksjon |
| :--- | :--- |
| `Space` / `→` / `↓` | Neste steg |
| `←` / `↑` | Forrige steg |
| `Q` | Åpne / lukke **Quiz & kontrollspørsmål** |
| `K` | Vis **QR-kode** for deling til elever |
| `F` | Fullskjermmodus |
| `Esc` | Lukk modal |

## Utvikling og bygging

```bash
npm install
npm run dev
```

Bygg produksjonspakke og selvstendig enkeltfil-HTML (`dist/Helse-og-Ernaering-Presentasjon.html`):

```bash
npm run deploy:standalone
```
